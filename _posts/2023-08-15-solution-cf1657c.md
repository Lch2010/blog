#### 题目大意

有 $$T$$ 组数据，每组给你一个 $$n$$，表示一个全部由 `(` 和 `)` 组成的长度为 $n$ 的字符串。当此时的前缀满足以下两种条件之一时即可操作：

- 这个前缀是一个合法括号序列。

- 此前缀是长度大于等于 $$2$$ 的回文串。

问最多能操作多少次以及最后剩下多少个字符。

#### 思路

- 当字符为 `(` 时，有两种选择 `()` 或 `((`。

- 当字符为 `)` 时，那么，就只有一种选择 `)((` $\cdots$ `()`。

那么不就很简单了？遍历一遍，`if` 语句判断。

#### AC code
```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;
signed main(){
	ios::sync_with_stdio(0);
	cin.tie(0);cout.tie(0);
	int T;
	cin>>T;
	while(T--){
		int cnt=0;
		int n;
		cin>>n;
		string s;
		cin>>s;
		int i=0;
		while(i<n-1){
			if(s[i]=='(')	i+=2,cnt++;
			else{
				int j=i+1;
				while(j<n&&s[j]!=')') j++;
				if(j==n)	break;
				i=j+1;
				cnt++;
			}
		}
		cout<<cnt<<" "<<n-i<<'\n';
	} 
	return 0;
}
```
