#### 题目大意

跟独木桥一样啊，就不多加赘述了，大家自己去看[这道题](https://www.luogu.com.cn/problem/P1007)吧。

#### 思路

很简单啊！就是独木桥的代码加上一个测多组数据，思路为：每次将 $l$ 和 $n$ 输入。然后输入 $n$ 个 $a$，每次记录两种答案，分别为：$\max_{ma1,\min_{a,l-a}}$ 和 $\max_{ma2,\max_{a,l-a}}$ 最后输出结果即可。又美滋滋的水了一道蓝。

至于证明，如下：

两个蚂蚁相遇后会掉头，就等同于根本就没有没掉头，因为走过的路程是一样的。

所以就可以把为题直接简化为开始时蚂蚁的方向，蚂蚁方向有两个，一个向左，一个向右。

所以，我们就可以得出上面的结论，答案分别为：向左向右最小或最大 的，最大值 $\max$。

#### AC code
```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    int T;
    cin>>T;
    while(T--){
    	int l,n,a,ma1=INT_MIN,ma2=INT_MIN;
        cin>>l>>n;
    	for(int i=1;i<=n;i++){
    		cin>>a;
    		ma1=max(ma1,min(a,l-a));
    		ma2=max(ma2,max(a,l-a));
    	}
    	cout<<ma1<<" "<<ma2<<"\n";
        
    }
	return 0;
} 
```
